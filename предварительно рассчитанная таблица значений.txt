В момент обновления значения с АЦП новое значение сравнивается со старым, и чтобы избежать дёрганья двигателя значение будет меняться плавно.
Будет посчитана разница между старым и новым значением, и будет подобрано значение dv означащее скорость изменения значения к новому, пока
значение изменяется новые числа загружаться не будут(ну ацп кнш будет всё равно работать но мне похуй по крайней мере сейчас). Когда новое значение
будет достигнуто будет загружено новое число. Скорость dv будет заранее посчитана таблицей чтобы сэкономить процовое время потому что stm32 не
шарят за матешу, только за арифметику. На случай внезапных застреваний плёнки будут добавлены также предельные значения выйдя за которые вся 
конструкция если и не остановится, то очень сильно замедлится и тем самым будет спасена плёнка и возможно остальная механика. Скорость dv тем 
выше, чем ниже значения полученые с ацп. Для скорости есть собственный график

В режиме перемотки будет ускоренный прирост который будет логарифмически замедляться при приближении к максимальной скорости. Торможение
будет идти по отдельному графику с быстрым снижением скорости до порога остановки. Если значение с ацп ниже значения начала отрезка то
обновление конечного числа будет произведено немедленно
