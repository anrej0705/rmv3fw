# rmv3fw
STM32F100 Прошивка для DIY-сканера 35мм киноплёнки

Всё что не отмечено в `пины.txt` "закончились ноги" означает что это не удалось реализовать на STM32F100 и возможно получится на STM32F107 так как там банально больше ресурсов доступно
